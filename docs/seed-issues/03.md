# Add dark-mode theme support to PayWithNaira and StatusTimeline

### Context
Both `src/PayWithNaira.tsx` and `src/StatusTimeline.tsx` currently apply hardcoded light palette inline styles (`#ffffff`, `#111827`, `#f3f4f6`, `#fef2f2`). DApps with dark interfaces or operating systems set to dark mode experience high contrast clashes and styling inconsistencies.

### Done when
- [ ] Both `PayWithNairaProps` and `StatusTimelineProps` accept an optional `theme?: "light" | "dark" | "system"` prop (defaulting to `"system"`).
- [ ] Dark theme palettes provide accessible contrast ratios (WCAG AA >= 4.5:1) for text, badges, backgrounds, borders, and buttons.
- [ ] System theme mode automatically listens to and responds to `window.matchMedia("(prefers-color-scheme: dark)")`.
- [ ] Unit tests in `test/PayWithNaira.test.tsx` and `test/StatusTimeline.test.tsx` verify theme styles in light, dark, and system modes.
- [ ] Documented in `docs/API.md`.
