# Add custom CSS className and style props to PayWithNaira and StatusTimeline

### Context
`src/PayWithNaira.tsx` and `src/StatusTimeline.tsx` currently apply hardcoded inline styles to their container `<div>` elements without accepting `className` or container `style` overrides. This prevents host applications from customizing outer margins, layout positioning, card shadows, or Tailwind/CSS module class names.

### Done when
- [ ] Add `className?: string` and `style?: React.CSSProperties` to `PayWithNairaProps`.
- [ ] Add `className?: string` and `style?: React.CSSProperties` to `StatusTimelineProps`.
- [ ] Forward `className` to the outermost container `<div>` element in both components.
- [ ] Merge `style` with `containerStyle` on the root elements, preserving responsive defaults while allowing custom overrides.
- [ ] Add unit tests in `test/PayWithNaira.test.tsx` and `test/StatusTimeline.test.tsx` verifying custom classes and styles are applied.
- [ ] Update `docs/API.md` with the new optional props.
