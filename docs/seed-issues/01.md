# Add CashOutToNaira component for off-ramp withdrawal flows

### Context
`src/PayWithNaira.tsx` provides the on-ramp deposit flow using `ramp.deposit`. `upstream/core-API.md` exports `ramp.withdraw(options)` and `ramp.completeWithdrawal(id)` on the `Ramp` client interface, but this repository currently lacks a counterpart off-ramp component for cashing out on-chain assets (e.g. USDC, NGNC) to Nigerian Naira bank accounts.

### Done when
- [ ] `src/CashOutToNaira.tsx` is implemented accepting props: `ramp: Ramp`, `assetCode: string`, `amount?: string`, `onComplete?: () => void`, `onError?: (error: NairaRampError) => void`, `label?: string`.
- [ ] On click, synchronously opens an anchor popup window via `window.open("", "nairaramp_anchor")` before awaiting `ramp.withdraw`, setting the popup destination when the interactive URL arrives.
- [ ] Automatically watches the withdrawal transaction via `ramp.watch` and triggers `ramp.completeWithdrawal` when the transaction status indicates user signature or payment submission is needed.
- [ ] Renders a fallback link (`"Continue to the anchor"`) if the popup window is blocked by the browser.
- [ ] Exported from `src/index.ts` with comprehensive unit tests in `test/CashOutToNaira.test.tsx`.
- [ ] Documented with props, lifecycle phases, and usage examples in `docs/API.md` and `README.md`.
