# Export Nigerian language label sets for StatusTimeline (Yoruba, Hausa, Igbo, Pidgin)

### Context
`src/StatusTimeline.tsx` supports an optional `labels` prop (`Partial<Record<TimelineStep, string>>`), but applications currently must manually author Nigerian language translations. Exporting pre-translated dictionary constants for Nigeria's most widely spoken languages (`YORUBA_LABELS`, `HAUSA_LABELS`, `IGBO_LABELS`, `PIDGIN_LABELS`) will streamline local adoption.
