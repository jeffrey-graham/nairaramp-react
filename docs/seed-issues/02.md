# Add useRampQuote hook for live rate estimation

### Context
`src/usePayWithNaira.ts` manages payment execution once initiated, but does not provide pre-transaction pricing information. In `upstream/core-API.md`, the `Ramp` client exports `ramp.getPrice(options: GetPriceOptions): Promise<Quote>`, returning `sellAmount`, `buyAmount`, `price`, and `totalFee`. Developers need a dedicated React hook to display conversion estimates and calculate fee breakdowns before the user clicks to pay.

### Done when
- [ ] `src/useRampQuote.ts` is created exporting `useRampQuote({ ramp, sellAsset, buyAsset, sellAmount?, buyAmount?, pollInterval? })`.
- [ ] Returns `{ quote: Quote | undefined, loading: boolean, error: NairaRampError | undefined, refresh: () => Promise<void> }`.
- [ ] Debounces rapid amount keystroke changes to prevent excessive anchor API calls.
- [ ] Automatically stops polling timers and cancels in-flight quote requests upon component unmount.
- [ ] Exported from `src/index.ts` with unit test suite in `test/useRampQuote.test.ts`.
- [ ] Documented with options, returns, and example snippets in `docs/API.md`.
